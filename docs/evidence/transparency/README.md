# Historical transparency evidence

These reports record the material, bucket, blend and depth state observed during
transparency investigations. They are development evidence, not game resources;
neither the injector nor its build reads them.

The decisions and interpretation are in [Transparency modes](../../../TRANSPARENCY_MODES.md).
Keep these reports unchanged, including the parked Mode 3 evidence. Capture
examples in that document write new reports to `/tmp` so they do not overwrite
this archive.
